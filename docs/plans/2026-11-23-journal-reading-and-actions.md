# 风格志：先读结论，再看变化

## 任务与范围

Victor 的验收标准是「经验的总结、具体的启发」。保留 My Colors / My Outfits 两章、已认可的扇形色卡、衣柜材质和原衣物吊牌尺寸。每个控件须对应明确任务，兼顾视觉、点击范围、摆放位置及返回路径。拒绝将小链接统一放大成一排浅色矩形。

本轮交付是已有 React 产品的本地实现与可操作预览；没有新增模型、账户配置、数据库写入或发布动作。原始快照与截图留在忽略目录，不提交用户衣物资料。

## 逐项交互链路

| 用户任务 / 原入口 | 本轮决定 | 进入与返回 |
|---|---|---|
| 选择色卡或穿搭 | 保留双语章节页签 | 原地切换，选中样式沿用墨色下划线 |
| 看黑白灰之外的倾向 | 三个直接可读结果，各配真实色卡 | 无需操作 |
| 看什么与什么一起出现 | 直接展示双样卡、真实分母和数量 | 删除每条“相关搭配”展开 |
| 比较相似配色 | 一处带标签的原生分组选择 | URL 保留 paletteGroup；选择时不回页顶 |
| 看整套配色来源 | 每套三列色卡是一个完整链接 | 搭配详情 → 返回我的色卡；保留组和阅读位置 |
| 角色筛选、全 HEX 列表、色系勾选、色系衣物展开 | 从分析页删除，避免重复查询任务 | 不再让用户先理解引擎分类 |
| 看穿搭观察 | 一处主题选择，结论与两套代表记录直接呈现 | URL 保留 insight；原话和案例同处 |
| 分析依据 | 删除展开控件 | 已引用原话直接可见；计算口径就地说明 |
| 逐套上一套/下一套 | 删除；桌面直接并列，手机横向翻阅 | 露出邻张和滚动条；容器可键盘滚动 |
| 生成更深入解读 | 保留唯一高强调“分析穿搭偏好” | 禁用、加载、失败可重试；无足够记录时解释条件 |
| 全量替换品类 → 替换对 → 来源 → 前后 | 收成最多三项具体变化 | 直接看一组原件/候选；来源写进标题 |
| 手机对比原件/候选 | 同位置切换一张原尺寸吊牌 | 墨底选中、48px目标；URL保留 idea/compare |
| 进入单品详情 | 整张原衣物吊牌 | 返回同一主题、候选及比较状态 |
| 搭配详情继续看单品 | 保留上下文 | 单品 → 返回搭配 → 返回风格志 |
| 读取失败、空衣柜、未确认颜色 | 各一条明确恢复路径 | 保留完整文字按钮，清除微小下划线重试 |

所有衣物图文仍用 WardrobeItemCard，桌面/平板/手机沿用原三列/两列/一列尺寸。整套对象复用 Best Match 的 TagBundle，无自制缩小衣物卡。色样均方形，不加圆点、勾选或选中描边。

## 迭代记录

1. 淘汰上轮“全部入口做整行浅色按钮”的方向：它保留了冗余任务，只扩大控件。
2. 第一版去除逐条展开，直接并列全部主色色卡；实际手机检查发现多层穿搭有7张色样，无法对齐比较，桌面也产生参差空洞。
3. 第二版固定上装/下装/鞋三列，每列用纸色卡承载等大小真实色样；相同 HEX 合并但保留衣物来源，不计算平均色。复杂穿搭不增加整套高度。缺鞋明确留空；等大色样不表示视觉面积。
4. 独立审查发现横向阅读和第二层详情会丢失上下文，补存容器位置、来源链接焦点与嵌套返回路径。

## 灵感的可信边界

调用现有推荐构建器后，重新核对当前完整搭配、已确认结构、主色关系和槽位；恰好一处替换，不遗漏第二件配饰；排除已存主件/备选组合及精确接受/拒绝记录。候选最多三条。同一槽位内换序不会制造新组合。没有可靠新候选时，清楚标明已存备选。

同步报告只保留既有文本内容；机会、概念关系和规则版本与当前 atoms/colors/cases 一起重算，避免新字段配旧候选。颜色统计口径未改；未知信息不当作黑白灰；替换不等于已验证的实穿效果。

## 验收证据

- `npm run lint`、`npm run build` 通过；构建仍有既有 bundle 体积和 Supabase 混合导入警告。
- 46 项相关测试通过，包括单处替换、上下文失效、拒绝/接受排除、色彩分母、未知颜色、原话校验与嵌套导航。
- 真实 101 件 / 43 套快照，桌面1440px、手机375/390px分别浏览。常规与多主色配色均固定三列，无页面横向溢出。手机每套配色约199px，复杂色样不再增加高度。
- 独立集成预览用原 BestMatchDetail/ItemDetail 和原路由，只替换两份 Context 数据；API与持久化锁在本机禁用。实走：手机第二套 → 搭配 → 单品 → 搭配 → 原风格志，主题、横向位置与焦点恢复；替换候选 → 单品 → 返回，idea/compare 保留。
- 本轮没有发送真实模型请求；沿用现有 Kimi 接入。UI故障状态在本地受控返回中检查，不能视为生产AI可用性实测。
- 截图与集成夹具在 `.local-data/ui-review/`，边界见 `INTEGRATION-FIXTURE.md`。
