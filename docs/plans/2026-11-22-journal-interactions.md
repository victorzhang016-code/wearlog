# 风格志入口与交互规范

Victor 的本轮要求：保留已认可的内容、信息层级和色卡形式；先梳理每个功能的使用链路，去掉零碎小链接和装饰箭头，统一形状、触控尺寸及入口位置。本轮局部调整交互，不更换视觉系统或分析规则。

## 参考与取舍

- [Atlassian Button](https://atlassian.design/components/button/usage)：动作标签说明结果；图标可选，多数按钮无需图标。衣LOG 去掉所有通用“文字＋右箭头”；返回方向、替换关系可保留有实际含义的图标。
- [Carbon Button](https://www.carbondesignsystem.com/building-blocks/core/components/button/guidelines)：单一高强调动作，相关操作就近成组。黑色按钮仅用于生成分析；阅读色卡不需要硬加主按钮。
- [GOV.UK Accordion](https://design-system.service.gov.uk/components/accordion/)：整个标题区域可触发；必要内容直接呈现，避免嵌套折叠。原色色卡直接显示，配饰/辅色统一切换，不再每套额外展开。
- [Adobe ColorSwatchPicker](https://react-spectrum.adobe.com/v3/ColorSwatchPicker.html)：颜色选择有命名、选中状态和一致形状。采用衣LOG已有方形纸色卡语言，不使用圆点替代色面。
- [WCAG 2.5.5](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html)：44 × 44 CSS px 是增强目标尺寸。项目按钮采用至少48px高，展开和记录行56px起，文字15–16px；不把透明热区当作视觉可发现性的替代品。

## 完整链路与入口决定

| 功能 | 用户的下一步 | 入口与位置 | 状态/返回 |
|---|---|---|---|
| 色卡/穿搭章节 | 换阅读主题 | 保留顶部双语章节入口 | 保留URL章节与选中下划线 |
| 概览、非基础色选择 | 直接理解颜色偏好 | 无按钮，不让静态信息假装能点 | 原统计与色扇不变 |
| 配色关系来源 | 看是哪几套支持这条统计 | 结论下方整行“相关搭配 · N套” | 同处展开/收起，列表每行进入对应搭配 |
| 相似配色范围 | 看常见组或全部组 | 分组标题下方选择框 | 切换范围，不在长列表末尾放收起按钮 |
| 主色/全部颜色 | 对照主色，必要时看配饰和细节 | 分组顶部统一显示选项 | 作用于整组比较；移除每套细节折叠 |
| 同组更多案例 | 比较真实色差 | 第一套色卡之后整行“同组其他N套” | 一层展开，无嵌套 |
| 查看搭配详情 | 看原始整套和故事 | 搭配名称与“搭配详情”合为整行导航 | 返回原风格志章节及颜色筛选 |
| 全部色卡按色系查找 | 选颜色，再看具体色号 | 方形纸色卡选择器，名称+数量+选中勾 | URL保存色系/角色；原色色卡直接显示 |
| 相关衣物 | 找到拥有这个颜色的衣物 | 原色色卡之后整行“相关衣物 · N件” | 展开原尺寸吊牌；底部“再显示N件” |
| 统计口径 | 核对算法范围 | 分组末尾整行“统计说明” | 低频按需展开 |
| 分析穿搭偏好 | 生成/刷新分析 | 偏好标题旁唯一黑色动作按钮 | 加载/禁用/失败保留原行为 |
| 分析主题 | 换一条结论 | 桌面文字选择组、手机下拉 | 明确选中，无跳转箭头 |
| 相关搭配 | 前后比较支持案例 | 名称导航行，下方成组“上一套/下一套”与计数 | 边界禁用，不循环迷失位置 |
| 分析依据 | 看原文与来源 | 结论卡末尾整行入口 | 来源名整行可点；删除重复当前搭配链接 |
| 同类替换 | 选品类、选两件、选案例、比较前后 | 沿用选择器与前/后切换；查看原搭配就近 | 明确状态，无泛用箭头 |
| 空状态 | 添加衣物、搭配或备选 | 一项有明确文字的动作 | 普通边框按钮，保留原目的地 |
| 单品详情 | 查阅档案 | 原衣柜吊牌整卡可点 | 原尺寸不变；返回来源章节 |

## 统一语法与验收

操作按钮、分段选择、整行展开、整行导航四种语法，不能互相冒充。所有展开统一原生 details/summary，右侧文字“展开/收起”；链接保持真实a语义，所有动作保持button语义。选中、焦点、悬停、禁用和加载可见。触控目标至少44px，不靠小字、下划线或右箭头暗示操作。

检查桌面与375/390px：入口位置、全行点击、键盘Enter/Space、筛选与空状态、分组对比、前后案例、来源跳转及返回、无水平溢出。改动仅本地预览，按项目UI规则在视觉确认后发布。

## 本地实现与验收

- `JournalControls.tsx` 统一展开行、记录导航和来源信息；两个详情页识别风格志来源，保留章节与色系/角色查询参数。返回不会保存之前的展开状态或精确滚动位置；跨页返回按钮尚未用正式登录会话验收。
- 取消所有通用右箭头，保留返回方向和替换关系本身。原色色卡直接显示；配饰/辅色统一由显示范围选择组控制；原生details内不再嵌套details。
- 原尺寸衣物吊牌不变。修复颜色角色无记录时整个色卡章节消失的问题，空结果现在只作用于筛选区域。
- 36项相关测试、lint、production build通过；构建保留原有大包和Supabase混合导入提示。Impeccable机械检测无命中，不能代替视觉或真人可用性判断。
- 真实快照浏览器验证：1440px桌面、375/390px手机；色系选中、18组/常见2组切换、完整颜色包含配饰与辅色、Enter展开/Space收起、前后案例1/2与2/2边界、分析依据。无页面水平溢出，已显示操作目标没有低于44px高度，未记录脚本错误。
