# 风格志：私人穿衣档案

## 任务与边界

Victor 认为交互改善后的页面仍然平淡，要求实际研究海报、杂志、拟物作品，以及《极乐迪斯科》和他保存的人物卡参考，并自主试做更独特的表现形式。本轮修改真实 React 页面，本地预览；不改分析算法、模型、数据或部署。功能链路沿用上一轮已经验证的版本。

## 图像与事实

- 用户衣物图片、搭配、原话及已确认 RGB：产品证据，直接用于页面中的原有吊牌/色卡。
- 书籍、游戏截图：仅参考构图、物件关系和材质，不复制到产品资源中。
- 现有衣LOG纸张/织物：沿用既有材质，低强度使用。
- 不生成服装、人体、人格或虚构风格属性；不以图块大小冒充面积/频率。
- 原 WardrobeItemCard 尺寸与样式锁定；整套封面可复用 Best Match 的原 TagBundle，明确标出图示范围。
- 上方已认可扇形色卡与两个章节架构保留。

## 场景与验收

用户打开自己的色彩和穿搭档案，先看到有主次的图像和一个清楚的判断，再对照真实来源。桌面应形成可辨认的跨页，而非连续同权重三栏；手机须重新组织阅读顺序，文字/图像/控件不可缩小凑排版。全物件仍为详情入口，返回恢复选项、阅读位置与焦点。

通过条件：有明确视觉中心、题材专属物件关系、正文清楚、真实色值无滤镜、原吊牌尺寸不变；375/390px 无横向页面溢出；选择、详情返回及空态正常；lint/build 通过。

## 三个构图的取舍

1. 穿衣档案扉页：一张浅色记录页与深色物件衬纸组成整体，穿搭与原话作为主体。选作穿搭章节。
2. 裁缝色样册：大主色纸、次色纸、连续纸页及组合并置。选作颜色章节，独立处理，不复制穿搭版面。
3. 私人时装杂志：照片与标题跨栏、大片白场。保留尺度意识；现有43套本地记录无整套照片，不能靠虚构模特照片支撑，因此不选为当前主方向。

选择依据是已存素材、用户实际任务与视觉差异。此次为用户授权的自主试做，尚未获得 Victor 对最终画面的审阅。

## 实现与审阅记录

首稿的问题与修正：

- 左右分区虽清楚，但纸纹过强：降低至10–12%，材质退到内容之后。
- 前两件按数组截取会只留下上装：改取第一上装和第一下装；两件单独呈现，手机用原mini规格并排，不把下装藏在叠牌底部。
- 初稿裤子遮住上装名称：扩大衣物场景份额，较窄容器改成上下跨页；601–750px原mini错位且不压住名称。
- 大数字与大色面争主次、三行配对太松：件数回正常字号，三组配色形成同张墨纸上的尺度差与错位，桌面配对页实测450px高。
- 手机微小下一页边缘像意外裁切：改为完整一组显示，保留明确左右滑动提示、键盘访问和阅读位置恢复。
- 引文从带aria-label的链接中移出，原话可独立朗读；图片与名称仍为完整搭配入口。

独立审阅认为主题专属性已由真实衣物、原吊牌和个人原话建立，可作为档案跨页实验第一版；与顶级参考之间仍有差距，不能用材质改善代替对人物选择的深入理解。本轮未扩展分析逻辑。

验收：

- 桌面1440、手机375/390和侧栏交界641/768/1101检查；页面无横向溢出。
- 原生选择器切换实际观察及来源；宽松统计仍是12套可比较、11套采用，原文无改写。
- 手机键盘横向翻阅、进入银色神装并返回，主题、横向位置和焦点恢复；紫色分组→车库→返回仍为原3套分组且焦点恢复。
